## 📌 About the Project

This project explores the **StudentsPerformance** dataset using Python.
It inspects student information and exam scores, summarizes score
distributions, checks for missing values, identifies potential outliers,
and exports a processed CSV file.

> 🎯 **Goal:** Understand the structure and quality of student
> performance data through a clear, step-by-step EDA workflow.



## 📊 Dataset Overview

  -------------------------------------------------------------------------------------
  Detail                              Description
  ----------------------------------- -------------------------------------------------
  Dataset                             `StudentsPerformance - StudentsPerformance.csv`

  Rows                                1,000 students

  Columns                             8 original columns

  Score columns                       Math, reading, and writing

## 🔍 Analysis Workflow

  -----------------------------------------------------------------------
  Step                                What the notebook does
  ----------------------------------- -----------------------------------
  1️⃣ Load                             Reads the CSV into a pandas
                                      DataFrame

  2️⃣ Inspect                          Checks rows, columns, data types,
                                      and sample records

  3️⃣ Summarize                        Generates descriptive statistics

  4️⃣ Validate                         Checks columns for missing values

  5️⃣ Standardize                      Trims whitespace and converts
                                      categorical text to lowercase

  6️⃣ Analyze                          Calculates mean, median, standard
                                      deviation, and quartiles

  7️⃣ Engineer features                Calculates total marks and
                                      percentage

  8️⃣ Detect                           Checks score columns for potential
                                      outliers using the IQR rule

  9️⃣ Export                           Saves the processed data as a CSV
                                      file
  -----------------------------------------------------------------------

## 🧮 Calculations

**Total marks**

``` python
total marks = math score + reading score + writing score
```

**Percentage**

``` python
percentage = (total marks / 300) * 100
```

## ▶️ How to Run

1.  Put the notebook and CSV file in the same folder.

2.  Open a terminal in that folder.

3.  Start Jupyter Notebook:

    ``` bash
    jupyter notebook
    ```

4.  Open `EDA_task7 (1).ipynb`.

5.  Run the cells from top to bottom.

### 📂 Local File Path

If the notebook contains a Google Colab path such as:

## ⚠️ Notes

-   The IQR method flags **potential** outliers; it does not prove that
    a score is incorrect.
-   Missing values are checked, but the current workflow does not impute
    them.
-   The current workflow does not remove outlier rows.
-   Plotting libraries are imported, but the current notebook cells do
    not generate charts.
-   The exported CSV is saved in the notebook's current working
    directory.
